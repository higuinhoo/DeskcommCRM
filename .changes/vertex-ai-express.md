titulo: O CRM agora conecta ao Google Cloud Vertex AI por API key
---

Agora é possível escolher Google Cloud Vertex AI como provedor de IA, cadastrar uma API key do modo Express e usar os modelos Gemini nos agentes e nos demais pontos de IA do CRM. A chave é validada diretamente na Vertex AI, fica cifrada como as outras credenciais e nunca é enviada pela URL.
